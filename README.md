# 三国杀 Ji

一个原生 macOS SwiftUI 入门版。每局由你和三名电脑玩家进行四人身份局。身份和武将都可随机，也可由你指定；四个座位分别为主公、忠臣、反贼和内奸。

## 启动

需要 macOS 14 或更新版本，以及 Swift 6 工具链。

```sh
cd /Users/hunter/Workspace/sanguosha-ji
swift run
```

也可以在 Xcode 中打开 `Package.swift` 并运行 `SanguoshaJi` scheme。要生成可双击启动的 `.app`：

```sh
./Scripts/package-app.sh
open "dist/三国杀 Ji.app"
```

## 基本玩法

1. 点“摸两张牌”。
2. 在“身份”和“武将”菜单选择身份、标准版武将，或选“随机”。电脑会从其余武将中随机选择，四名角色不会重复。点选手牌：基本牌和锦囊会直接结算；需指定目标的牌会高亮合法角色。装备会进入对应装备栏。
3. 遭到杀或群体锦囊时，按提示打出闪或承受伤害。体力到 0 时，存活角色按顺序获得使用桃救援的机会。
4. 点“结束回合”。电脑按 520 毫秒间隔逐步播放摸牌、装备、出牌和响应。战报可滚动回看并自动跟随最新行动。
5. 角色名下会显示武将和装备。右侧常驻显示你的武将技能。

主公和忠臣要消灭反贼与内奸；反贼要杀死主公；内奸要成为最后的生还者。四人局按标准配置各一名。主公额外增加 1 点体力上限。规则说明也在游戏右侧与“新手规则”窗口中。

## 规则范围

本项目使用四人身份配置（主公、忠臣、反贼、内奸各一名）、隐藏身份、起手四张、摸两张、回合流程、杀闪桃、濒死求桃、手牌上限、击杀反贼奖励、主公误杀忠臣惩罚和身份胜负判断。标准牌堆为 108 张，含 4 张 EX：基本牌 53 张、锦囊牌 36 张、装备牌 19 张。每张牌保留标准花色和点数，八卦阵会翻开牌堆顶牌，红色视为闪、黑色判定失败，并将判定牌放入弃牌堆。

战斗记录会写明攻击者、目标、伤害来源和击杀者。电脑座位会显示为其武将名。

武将选择覆盖标准版 25 名：魏 7 名、蜀 7 名、吴 8 名、群雄 3 名。当前只实现了部分武将技能，其他武将的名称、体力上限和技能说明可见。装备区含武器、防具、进攻马和防御马；部分武器特效仍待实现。南蛮入侵要求杀响应，万箭齐发要求闪响应。五谷丰登会亮出与存活角色数相等的牌，并从使用者开始按座次逐人选择；电脑会按手牌和体力评估选择。无懈可击现在有完整的轮流响应和反制链；决斗现在会让双方轮流打出杀，无法响应的一方受伤。

**仍未完整实现的规则**：闪电仍简化为 1 点伤害，未按黑桃 2–9 判定 3 点雷电伤害或传递；乐不思蜀尚未翻判定牌，当前会直接跳过出牌阶段；无中生有仍简化为摸两张牌，未让全体选择亮出的牌；借刀杀人仍简化为弃置目标武器；仁王盾、寒冰剑、青釭剑、贯石斧等特效未完整实现。25 名武将仅部分技能可用，电脑策略也未覆盖全部技能和局势。因此目前仍是可玩的入门实现，不是完整标准版规则引擎。
