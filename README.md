# 三国杀 Ji

一个原生 macOS SwiftUI 身份局游戏。支持 4–8 人，由你和电脑玩家同桌。身份和武将都可随机，也可由你指定。窗口里的“新手规则”是帮助说明，不代表另有一套入门规则。

## 启动

需要 macOS 14 或更新版本，以及 Swift 6 工具链。

```sh
cd /Users/hunter/Workspace/sanguosha-ji
swift run
```

也可以在 Xcode 中打开 `Package.swift` 并运行 `SanguoshaJi` scheme。要生成可双击启动的 `.app`：

```sh
./Scripts/package-app.sh
open "dist/三国杀 Ji.app"
```

## 基本玩法

1. 点“摸两张牌”。
2. 在人数菜单选择 4–8 人局，再从“身份”和“武将”菜单选择身份、标准版武将，或选“随机”。电脑会从其余武将中随机选择，角色不会重复。点选手牌：基本牌和锦囊会直接结算；需指定目标的牌会高亮合法角色。装备会进入对应装备栏。
3. 遭到杀或群体锦囊时，按提示打出闪或承受伤害。体力到 0 时，存活角色按顺序获得使用桃救援的机会。
4. 点“结束回合”。电脑按 520 毫秒间隔逐步播放摸牌、装备、出牌和响应。战报可滚动回看并自动跟随最新行动。
5. 角色名下会显示武将和装备。右侧常驻显示你的武将技能。

主公和忠臣要消灭反贼与内奸；反贼要杀死主公；内奸要成为最后的生还者。主公额外增加 1 点体力上限。规则说明也在游戏右侧与“新手规则”窗口中。

## 规则范围

本项目支持 4–8 人身份配置、隐藏身份、起手四张、摸两张、回合流程、杀闪桃、濒死求桃、手牌上限、击杀反贼奖励、主公误杀忠臣惩罚和身份胜负判断。标准牌堆为 108 张，含 4 张 EX：基本牌 53 张、锦囊牌 36 张、装备牌 19 张。每张牌保留标准花色和点数。闪电与乐不思蜀按判定牌结算；过河拆桥和顺手牵羊可选择手牌、装备区或判定区的具体牌；借刀杀人可指定刀的目标并让持刀者决定出杀或交刀。八卦阵会翻开牌堆顶牌，红色视为闪、黑色判定失败，并将判定牌放入弃牌堆。

战斗记录会写明攻击者、目标、伤害来源和击杀者。电脑座位会显示为其武将名。

武将选择覆盖标准版 25 名：魏 7 名、蜀 7 名、吴 8 名、群雄 3 名。当前只实现了部分武将技能，其他武将的名称、体力上限和技能说明可见。装备区含武器、防具、进攻马和防御马；部分武器特效仍待实现。南蛮入侵要求杀响应，万箭齐发要求闪响应。五谷丰登会亮出与存活角色数相等的牌，并从使用者开始按座次逐人选择；电脑会按手牌和体力评估选择。无懈可击现在有轮流响应和反制链，决斗会让双方轮流打出杀，无法响应的一方受伤。

## 尚未完成的设计与规则

这是当前实现的缺口，不是“入门场”额外要求。按影响排序：

1. **无懈可击目标范围**：单目标锦囊已有反制链；多目标锦囊仍把所有目标共用一条反制链，没有逐目标独立询问和结算。
2. **装备特效**：八卦阵判定、仁王盾免疫黑色杀、青釭剑无视防具、诸葛连弩可连续出杀；雌雄双股剑、寒冰剑、青龙偃月刀、丈八蛇矛、麒麟弓、贯石斧、方天画戟的特效仍未完整实现。武器攻击范围和两种马的距离已实现。
3. **武将技能**：当前只接入少量技能或技能的一部分。张飞咆哮、赵云龙胆、诸葛亮空城、马超马术、吕蒙克己、周瑜英姿和黄月英集智有对应结算；曹操奸雄、司马懿反馈、许褚裸衣也只有简化或不完整结算。其余武将技能，以及护驾、鬼才、刚烈、突袭、遗计、倾国/洛神、仁德、武圣、观星、铁骑、奇才、制衡、奇袭、苦肉、反间、国色/流离、谦逊/连营、结姻/枭姬、急救/青囊、无双、离间/闭月等主动技能或触发技尚未完整实现。
4. **电脑决策**：电脑能逐步行动并处理部分响应，但身份推理、技能发动时机、装备/锦囊取舍和濒死救援策略仍比较简单。

上面这些需要按选定的标准版规则基线逐项实现并补测试。身份局人数可在顶部菜单切换；“新手规则”只是一份帮助说明。已有的 108 张标准牌堆、身份目标、摸牌/出牌/弃牌、常见基本牌和部分锦囊/武将技能，不等于完整标准版规则引擎。
